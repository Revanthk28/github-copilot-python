# GitHub Copilot Python — Sudoku Flask App

This repository contains a legacy Flask Sudoku application. A baseline pytest test suite has been added under `starter/tests`.

Running the baseline tests

1. Install dependencies for the starter app (if you haven't already):

   cd starter
   pip install -r requirements.txt

2. Run the tests from the starter directory using the exact command:

   python -m pytest -q

Notes

- The test suite should be run from the `starter` directory because the tests and `requirements.txt` used for the test environment are located there.
- The tests exercise the Sudoku logic and the Flask endpoints as a baseline before any refactor.
